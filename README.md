## Explore

- **Boot the CRT.** Move your pointer over the monitor to tilt it. The custom reticle adapts to links and project cards.
- **Open the terminal.** Try `help`, `whoami`, `projects`, `stack`, or `contact`.
- **View the game case studies.** See *Phantom Echoes Chapter I*, released on Steam, and *The Last Peg*, a five-player multiplayer game in development.

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`. The site uses HTML, CSS, and JavaScript without a build step. GitHub Pages serves the root of `main`.
