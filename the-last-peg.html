THE PREMISE

What’s in your glass?

Five players take a seat at an underground bar. One of the glasses is poisoned. A safe drink grants an ability, so taking a chance can give you an edge later in the match.

The shared table is where every decision plays out. Players can see each other, read the room, and change their minds about whom to trust.

FIVE SEATS / ONE SESSION

How the session moves

Expand each stage to see what the player does and what the game handles behind the scenes.

01 · Join the lobby

Sign in, then create or join a table. A join code lets friends enter the same session.

02 · Take a seat

The match starts with five players at one table. Everyone reads the room and decides whether to take a chance on their glass.

03 · Resolve the round

A safe drink grants an ability. The poisoned glass changes who survives and how the rest of the table plays the next round.

DEVELOPMENT NOTES

What went into it.

01 / NETWORKING

When the host leaves

Unity Netcode for GameObjects and Relay connect the players. Distributed Authority lets the match continue when the original host disconnects.

02 / PLAYER DATA

From sign-in to play

Authentication identifies the player, while Cloud Save stores player data separately from the live match.

03 / ART DIRECTION

A table you can read

Worn leather, crimson, and muted brass set the mood. Keeping the center clear helps players track glasses and pay attention to the other seats.
